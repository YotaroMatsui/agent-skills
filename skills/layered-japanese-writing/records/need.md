# Skillニーズ記録

- 記録ID: LJW-NEED-001
- 状態: 選定
- ニーズまたは問題: LLMが生成または校正する日本語長文について、表層規則だけでなく、境界付き完全性、再帰的な依存閉包、抽象階層、局所情報量を扱う再利用可能なSkillが必要である。
- 想定利用者: 日本語の技術文書、解説記事、設計文書、書籍原稿を作成またはレビューする利用者とAgent。
- ステークホルダーと期待: 読者は全体像から必要な詳細へ進めることを期待し、執筆者は機械検出と意味判断の境界を明確にしたい。
- 想定利用文脈: 長文の新規執筆、構成変更を伴う校正、LLM生成文の意味レビュー、文書品質の回帰評価。
- 反復性または影響度: 反復性が高く、誤った単純化や前提欠落は理解、設計判断、運用判断へ影響する。
- 既存Skillとの重複・隣接領域・未充足領域: `japanese-tech-writing`は段落、論証、読者負荷、冗長性を扱うが、知識契約、依存閉包、再帰的階層、MindMap投影を明示的なOutcomeとして扱わない。textlint、prh、ja-lint型の仕組みは決定的な表層検出に強いが、意味上の完全性を判定できない。
- 期待便益: 意味構造と表層検査を分離し、再現可能なlintと根拠付き意味レビューを組み合わせられる。
- リスク: 階層化の過剰適用、文字数閾値の目的化、LLM評価者への過信、完全性の無制限な主張。
- 費用または制約: 対象読者と原資料の特定、意味レビュー、人間による高影響文書の受入れが必要になる。
- 決定: 一つの一般Skillとして設計し、決定的lintはEnablerとして同梱する。独立したlint Skillへの分割は、利用実績から責務が独立した場合まで保留する。
- 根拠と証拠: ユーザーが提示した構想、既存`japanese-tech-writing`、textlint/prhの責務、公開コードを確認できないja-lintの紹介、LLM自己批評とLLM評価の既知の限界。
- 未解決事項: 文書種別別の情報予算、実読者による理解時間と回答精度、意味レビューの評価者間一致は、運用データで校正する必要がある。

# 階層型日本語文書

## Purpose

対象読者が無関係な文脈を保持し続けなくても必要な知識へ到達できるよう、境界付き完全性、抽象階層、依存関係の閉包を備えた日本語説明文を確立する。

ここでいう完全性は、世界についての無制限な網羅性ではない。
完全性は、宣言した読者、目的、対象範囲に必要な依存知識が、本文内で解決されるか外部前提として明示されている状態を指す。

## Outcomes

- O1: 文書が満たす読者、目的、対象範囲、除外範囲、および受入条件が判別できる状態にある。
- O2: 文書の主要命題が、役割と抽象度を区別できる階層に配置されている。
- O3: 各命題の理解に必要な用語、前提、根拠、および具体化への到達経路が追跡可能である。
- O4: 各節および段落の情報量が、対象読者と文書目的に照らして局所的に処理できる範囲にある。
- O5: 見出しと主題文から復元した構造が、文書の論証方向と詳細化の経路を保持している。
- O6: 原資料または既存原稿がある場合、その事実、条件、不確実性、および出典の意味が、変更箇所でも保持されている。
- O7: 解消していない知識依存と判断上の限界が、読者に見える状態にある。

## Activities & Tasks

以下のActivityとTaskの記載順は、固定した実行順序を定めない。
文書の状態に応じて反復し、文書全体、節、段落、命題の各階層へ再帰的に適用してよい。

### 知識契約の設定

1. K1: 対象読者が既に持つ知識、文書を読む目的、および読後に可能になる判断または行為を識別する必要がある。
2. K2: 文書が扱う対象範囲と扱わない範囲を識別する必要がある。
3. K3: 対象範囲内の完全性を判定するため、必要な命題、前提、および証拠の条件を識別する必要がある。
4. K4: 確認できない前提は、既知の事実として補完してはならない。
5. K5: 読者または目的が複数ある場合、競合する受入条件を分離するのが望ましい。

### 抽象階層の整合

1. H1: 主要命題、補助命題、定義、根拠、例、および手順の役割を区別する必要がある。
2. H2: 同じ親に属する要素は、比較可能な抽象度と分解基準にそろえるのが望ましい。
3. H3: 抽象的な命題を現在の層だけで理解できない場合、必要な具体化または外部前提への到達経路を設ける必要がある。
4. H4: 下位層で新たに導入した依存知識にも、同じ閉包条件を適用する必要がある。
5. H5: 詳細化が文書目的に関係する不確実性を減らさない場合、それ以上の分解を停止してよい。

### 局所構成の形成

1. L1: 一つの節または段落には、一つの主要な伝達目的を割り当てる必要がある。
2. L2: 各段落の主題と、直前の段落または上位見出しとの論理関係を判別できるようにする必要がある。
3. L3: 根拠、例、および例外は、それが支える命題の近くに配置するのが望ましい。
4. L4: 節または段落が局所的な情報予算を超える場合、命題の分離、下位層への移動、または外部参照によって負荷を下げるのが望ましい。
5. L5: 文章量の削減によって必要条件や不確実性が失われる場合、その削減を行ってはならない。

### 意味と構造の検証

1. V1: 文書の階層、論証方向、および依存関係の到達可能性を、本文から独立して確認できる表現に投影して評価する必要がある。
2. V2: 各主要命題について、対象読者が理解または判断に必要とする依存知識が閉じているかを評価する必要がある。
3. V3: 修正後の事実、条件、不確実性、および出典を原資料と照合する必要がある。
4. V4: 決定的なlintの結果を、意味上の完全性または認知負荷の最終判定として扱ってはならない。
5. V5: 未解消の依存、判断保留、および適用限界を記録する必要がある。
6. V6: 高影響の文章では、起草とは独立した観点による意味レビューを取り入れるのが望ましい。

## Inputs

- 校正または執筆の対象となる日本語文書、構想、または素材。
- 対象読者、文書目的、対象範囲、および期待する読後行動に関する情報。
- 事実、仕様、出典、用語集、および既存の文章規範。

## Outputs

- 階層と依存関係を整えた日本語文書。
- 文書の命題階層またはアウトライン投影。
- 未解消の知識依存、意味上の判断、およびlint所見。

## Entry Criteria

- 対象となる文章または伝えるべき知識が利用できる。
- 対象読者と文書目的を、明示情報または妥当な仮定から識別できる。
- 事実性を要求する文章では、照合に必要な根拠資料を利用できる。

## Exit Criteria

- O1からO7の達成状況を、本文、構造投影、およびレビュー所見から評価できる。
- 未解消の重大な依存または意味の変化が、解消されるか明示されている。
- 文書が想定される受領先で利用できる形式にある。

## Controls

- ユーザーが指定した目的、文体、構造、用語、および出力形式を優先する。
- 原資料、引用、出典、適用法令、組織の文章規範、およびドメイン固有の定義に従う。
- 事実、推測、提案、および例を区別する。

## Constraints

- 読者の理解そのものを保証できると表現してはならない。
- 文字数、見出し深さ、段落数などの一律な閾値を、すべての文書に共通する品質基準として扱ってはならない。
- 文学作品、広告コピー、会話文など、意図的な曖昧さやリズムが価値を持つ文章へ、説明文の階層構造を無条件に強制してはならない。
- 根拠資料にない定義、因果関係、具体例、または断定を、閉包を埋めるために創作してはならない。

## Enablers

- 日本語の文章構成、論証、対象領域、および編集に関する能力。
- 見出し、段落、命題、および依存関係を抽出できる解析手段。
- 機械的な表層規則と構造上のヒューリスティックを検出するlintハーネス。
- 原資料と修正文の意味を比較できるレビュー能力。

## Common Approach

この節は参考情報であり、規範上の強さを持たない。

1. 文書全体について、読者、目的、範囲、必要な判断を一枚の知識契約にする。
2. 主要命題を根に置き、定義、根拠、例、例外を子として配置する。
3. 各節を局所的に読める単位へ整え、未解消の依存を上位または下位の層へ接続する。
4. 見出しと主題文からアウトラインを復元し、論証と詳細化の経路が残るか確認する。
5. 決定的lint、意味レビュー、人間の受入れを別の判定として扱う。
